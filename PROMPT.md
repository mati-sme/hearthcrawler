# Build: HEARTHCRAWLER — a mobile web survival base-builder where your base is a moving caravan

You are building a complete, polished, single-player mobile web game in THIS directory (/workspace/projects/hearthcrawler).
Vanilla HTML/CSS/JS, no build step, no external libraries, no CDN, no network calls, no paid APIs. All art is drawn in code on a 2D canvas (top-down). It will be hosted on GitHub Pages at https://mati-sme.github.io/hearthcrawler/ (so all paths must be RELATIVE).
Do NOT spawn subagents. Do not git push or create repos (the orchestrator does that). You may `git add`/`git commit` locally.

## Audience & feel
- Player: an adult who loves mobile games; his kids (4 and 6) also play. NON-GORY: no blood, no corpses. Defeated mobs "poof" into a puff of sparkles/smoke and drop loot. Raiders are goofy masked bandits who flee/"poof" ("Ouch!"), not killed graphically. Cute but clean art style: soft shadows, rounded shapes, nice palette per biome.
- Inspired by Rust (gather → craft → build → defend), but original: the base is a CARAVAN — a big crawler/wagon pulled by a mechanical ox-beast or engine that travels across a world map between biomes.
- CRITICAL DESIGN GOAL — DOPAMINE, NEVER STUCK: the last game the player got felt "decremental" and got stuck. So:
  - A always-visible GOAL TRACKER (top of screen, 1 current goal + reward) with a chain of ~40+ quests that come every 1–3 minutes (gather 10 wood → craft stone axe → build workbench module → survive first night → travel to next biome → beat boss...). Each goal pays rewards (resources, a blueprint, XP) with a satisfying popup, confetti/sparkle burst and sound.
  - Player XP/levels with a level-up fanfare and a small perk choice (pick 1 of 3: +gather speed, +max HP, +move speed, +damage, +carry, +turret dmg, etc.).
  - Frequent floating "+3 wood" pickups, combo/crit popups, loot chests that spawn in the world, daily-ish "lucky crate" on each new day.
  - NEVER WALL: resources always respawn; if the player dies they respawn at the caravan keeping everything except losing a small % of carried (not stored) resources; difficulty scales gently; there is always an affordable next upgrade; if the player is short on something, the goal tracker hints where to get it. Cost curves are gentle (roughly ×1.5 per tier), income grows faster than costs via tools/modules/perks.
  - After the final boss, endless mode: keep traveling, harder zones ("Distance 7, 8, 9...") with scaling rewards and new cosmetic caravan paint unlocks so progress never stops.

## Orientation & controls
- Lock PORTRAIT (manifest "orientation":"portrait"; if the device is landscape show a friendly "rotate your phone" overlay). Design for 390x844 CSS px, scale crisply with devicePixelRatio (cap DPR at 2 for perf).
- INVISIBLE FLOATING JOYSTICK: touching anywhere in the lower ~60% of the play area (not on a button) spawns the stick at the touch point; drag to move; a faint ring/knob appears only while dragging. Analog speed. Pointer Events with setPointerCapture; touch-action:none; prevent page scroll/zoom/double-tap zoom. Desktop fallback: WASD/arrows + mouse.
- Auto-actions to keep it simple for kids: walking near a tree/rock/scrap pile/bush AUTO-GATHERS with the equipped tool (swing animation); nearby enemies are AUTO-ATTACKED with the equipped weapon (melee swing or ranged shot). One big contextual ACTION button (bottom-right) for special actions (e.g. "Dodge roll", or "Enter caravan" when near it). Icon-first UI: big round buttons with emoji/canvas icons and small numbers, minimal text.
- Reference joystick code from another of the user's games is in /tmp/joy_ref.js (pointer-capture floating stick) — reuse ideas freely.

## Core systems
1. Resources: Wood, Stone, Scrap, Food (berries/hunted critter meat drawn as cute drumsticks — keep non-gory: critters drop "food bundles"), plus Gems/Cloth/Fuel at later tiers optional. Carry capacity on the player; deposit into caravan Storage automatically when near the caravan.
2. Survival stats: Health and Hunger bars (icons). Hunger slowly drains; eat automatically from food when below 50% (or tap the food icon). Starving drains health slowly (never instant death). Health regenerates when fed and near caravan beds.
3. Crafting tiers (opened from a CRAFT button / or inside caravan panel): Tier 0 by hand: Stone Axe, Stone Pick, Spear, Bandage. Tier 1 (needs Workbench module): Metal Axe, Metal Pick, Bow (ranged), Leather/Scrap Armor. Tier 2 (Workbench Lv2 + Furnace): Crossbow, Steel tools, Bomb (cartoon), Medkit. Tier 3 (Workbench Lv3): Blaster (sparkly energy bolts), Power tools. Tools increase gather speed/yield; weapons have damage/range/speed. Equip best automatically (with option to swap).
4. CARAVAN MODULES (the heart): the caravan is drawn as a visible vehicle in the world made of a grid of slots (e.g. starts 2x2, expands to 3x3/3x4 with "Chassis" upgrades). Each module is visibly drawn on the caravan and has levels 1–5: Storage (capacity), Workbench (unlocks craft tiers), Bed (respawn + heal + skip night option once unlocked? keep night meaningful but short), Furnace (smelts scrap → metal plates, cooks food for bigger hunger restore), Turret (auto-shoots enemies near the caravan, upgradable dmg/range/fire rate), Walls/Armor plating (caravan HP and damage reduction), Engine (travel speed & fuel efficiency), Garden (slowly generates food), Lantern (light radius at night, scares weak mobs). Building opens a nice bottom-sheet panel with the caravan grid; tap slot → choose module → cost shown with green/red resource icons. Built/upgraded modules pop with an animation.
5. Day/night cycle: ~3 min day, ~1.5 min night (show sun/moon clock icon). Night darkens the screen with a radial light around the player, caravan lanterns and turret glow (do this efficiently: render darkness on an offscreen canvas with 'destination-out' gradients, or a single gradient overlay). Night spawns more & tougher mobs that converge on the caravan; the caravan has HP; if it drops to 0 it doesn't die — it's "damaged" and modules work at half power until repaired with scrap (never a game over).
6. Travel / world map: a WORLD MAP button shows a node map of zones (like a road map): Meadow (start) → Pine Forest → Rocky Badlands → Scrap Wastes → Frost Peaks → Ember Volcano → endless "Far Roads". Each zone has its own palette, resource mix (better resources farther), mob set, and a Distance number that scales difficulty. Traveling costs fuel (wood/scrap → fuel) and is a short animated sequence where the caravan rolls along (~5–10 s) possibly with a random roadside event (ambush, wandering trader, loot crate). Arriving generates a new procedural zone around the caravan (seeded). Player can also go back to earlier zones. Requirements to reach a zone are soft: e.g. Engine Lv N and some fuel — always reachable with a bit of grinding, and the goal tracker guides it.
7. Mobs (non-gory, cute-menacing): Critters (bunnies/boars-like "Snortles" that flee or charge, drop food), Wolves-ish "Howlers" at night, Slimes, Scrap Bots, Raiders (masked bandits, melee and slingshot variants, raid the caravan at night), Frost yetis, Ember imps. 2 BOSSES with big health bars and telegraphed attacks (red circle warnings) — e.g. "Big Boar King" in the Pine Forest/Badlands and "Raider Warlord on a War-Wagon" in Scrap Wastes, plus final "Ember Golem" in the Volcano. Boss defeat = huge reward explosion + new blueprint + caravan paint.
8. Progression rewards: XP, levels, perks, blueprints, caravan paints/flags (cosmetic, a "Garage" panel), achievements list with stars.

## UI layout (portrait 390x844)
- Top: compact HUD row: Health heart bar, Hunger drumstick bar, day/night clock, Distance/zone name. Below it the GOAL card (icon + short text + progress x/y + reward icons).
- Right side vertical stack of round icon buttons: 🛠 Craft, 🏠 Caravan (build), 🗺 Map, 🎒 Inventory/Gear, ⚙️ Settings (sound toggle, reset save with confirm).
- Bottom: resource strip (wood/stone/scrap/food/metal counts with icons) and big ACTION button bottom-right.
- Panels are bottom sheets with big tappable cards (min 48px targets), close with X or tapping backdrop. Pause the world while a panel is open (optional at night; simplest: pause always).
- First-run: 3-step super short tutorial overlay with a hand icon showing "drag anywhere to move".
- Respect safe areas (env(safe-area-inset-*)), viewport-fit=cover.

## Tech requirements
- Files: index.html, style.css, js/*.js (split into sensible modules: e.g. main.js, input.js, world.js, entities.js, caravan.js, ui.js, data.js, audio.js, save.js, render.js), manifest.webmanifest, sw.js, icons/icon-192.png + icon-512.png (generate PNGs: write a small Node or Python script that draws the icon (caravan on a circle) — python3 with only stdlib (zlib/struct) PNG writer is fine; or node with pure JS PNG encoding), README.md.
- Use plain <script> tags (or ES modules with relative paths) — must work from GitHub Pages subpath and offline.
- 60fps on a phone: requestAnimationFrame with fixed-timestep update (dt clamped), object pooling for particles/projectiles, spatial culling (only draw what's on screen), cache static terrain decorations to an offscreen canvas per chunk, avoid per-frame allocations in hot loops, no shadowBlur in hot paths, cap entity counts.
- World: a bounded zone (e.g. 3000x3000 px) with tiles/ground texture, decorations, resource nodes that respawn, camera follows player smoothly.
- Audio: tiny WebAudio synth SFX (gather chop, pickup blip, hit, level-up jingle, goal-complete fanfare), started after first user gesture, mute toggle.
- AUTOSAVE to localStorage (key 'hearthcrawler-save-v1') every ~10 s and on visibilitychange/pagehide; versioned save with safe migration/try-catch (corrupt save → start fresh, never crash). Save: resources, inventory, equipment, caravan modules, zone, distance, quest index, xp/level/perks, day time, cosmetics, settings.
- PWA: manifest (portrait, standalone, theme color), sw.js caching all assets with a versioned CACHE name (cache-first, network fallback, clean old caches); register the SW from index.html with relative path; works offline after first load.
- TEST HOOKS: expose `window.__HC` with { state, step(n) (advance simulation n fixed steps synchronously), giveAll(n) (debug add resources), setTime(t), questIndex(), version } so the orchestrator's headless tests can drive and inspect the game. No console errors or warnings in normal operation.
- No console.log spam.
